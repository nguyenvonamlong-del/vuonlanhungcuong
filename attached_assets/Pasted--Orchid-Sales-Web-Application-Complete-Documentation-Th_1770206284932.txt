## System Overview

### Purpose
A comprehensive web application for managing an orchid business end-to-end, supporting:
- Supplier management
- Inventory tracking
- Customer orders (custom compositions and pre-made pots)
- Technician operations
- Delivery logistics
- Two ordering channels: website checkout and AI chatbot
- Pre-made orchid pot catalog with browsing and shopping cart
- Multi-language support (Vietnamese and English)
- Role-based access control (RBAC)
- VietQR payment integration for Vietnam market

### Technology Stack
- **Frontend**: React 18+ with TypeScript
- **Routing**: React Router (Data mode)
- **Styling**: Tailwind CSS v4
- **State Management**: React Context API
- **Icons**: Lucide React
- **Charts**: Recharts
- **Backend**: RESTful API
- **Database**: PostgreSQL
- **Payment**: VietQR API integration
- **Authentication**: JWT-based

## Business Rules

### Order Creation
1. **Minimum Quantity**: Each pot must contain at least 5 orchids
2. **Deposit Requirement**: 50% deposit required before confirmation
3. **Stock Validation**: Check availability before order confirmation
4. **Phone Format**: Vietnamese format /^0\d{9,10}$/

### Order Status Workflow
- PENDING → CONFIRMED (requires deposit payment)
- CONFIRMED → PREPARING (requires technician assignment)
- PREPARING → READY (technician completes work)
- READY → SHIPPING (package handed to shipper)
- SHIPPING → DELIVERED (requires remaining payment)
- Any status → CANCELLED (with reason)

### Inventory Management
- Stock deducted on order CONFIRMED
- Stock returned on order CANCELLED
- Low stock alert when quantity < min_order_quantity * 10
- Automated transaction logging

### Payment Processing
- Deposit: 50% of total, paid before confirmation
- Remaining: 50% of total, paid on delivery or in advance
- QR code generated for bank transfer
- Manual verification by staff

## VietQR Payment Integration

### Overview
VietQR is a standardized QR payment system in Vietnam that enables instant bank transfers through QR code scanning. The integration provides a seamless payment experience for Vietnamese customers.

### VietQR API Documentation
- **Official Website**: https://www.vietqr.io
- **API Documentation**: https://www.vietqr.io/danh-sach-api
- **Supported Banks**: 40+ Vietnamese banks (VCB, TCB, MB, ACB, etc.)

### Configuration Requirements
1. **Bank Information**
   - Bank ID (e.g., VCB for Vietcombank)
   - Account Number
   - Account Holder Name
   - Branch (optional)

2. **QR Code Templates**
   - `compact`: Minimal QR with bank info
   - `compact2`: QR with amount and description
   - `print`: High-quality for printing
   - `qr_only`: Just the QR code image

### Implementation Details

#### 1. QR Code Generation
**URL Format:**
```
https://img.vietqr.io/image/{BANK_ID}-{ACCOUNT_NO}-{TEMPLATE}.jpg?amount={AMOUNT}&addInfo={DESCRIPTION}&accountName={ACCOUNT_NAME}
```

**Parameters:**
- `BANK_ID`: Bank identifier (e.g., VCB, TCB, MB)
- `ACCOUNT_NO`: Bank account number
- `TEMPLATE`: QR template type
- `amount`: Transaction amount in VND
- `addInfo`: Payment description/reference (URL encoded)
- `accountName`: Account holder name (URL encoded)

**Example:**
```
https://img.vietqr.io/image/VCB-1234567890-compact2.jpg?amount=1250000&addInfo=ORCHID%20ORD12345&accountName=VUON%20LAN%20HUNG%20CUONG
```

#### 2. Payment Flow
1. **Order Creation**
   - Customer creates order
   - System calculates 50% deposit amount
   - Generate unique order reference code

2. **QR Code Display**
   - Generate VietQR URL with order details
   - Display QR code in payment step
   - Show manual transfer details as fallback
   - Include copy buttons for easy transfer

3. **Payment Verification**
   - Customer scans QR and pays via banking app
   - Customer uploads payment proof (optional)
   - Staff manually verifies payment
   - Update order status to CONFIRMED

4. **Automatic Verification (Future Enhancement)**
   - Webhook from bank for instant confirmation
   - Transaction matching by reference code
   - Automatic order status update

#### 3. Security Considerations
- Never expose bank credentials in frontend
- Store bank config in environment variables
- Validate all payment proofs server-side
- Implement rate limiting on QR generation
- Log all payment transactions

#### 4. Error Handling
- Fallback to generic QR generator if VietQR fails
- Display manual transfer instructions
- Timeout handling for slow networks
- Clear error messages in both languages

#### Generate Payment QR


## Pre-Made Orchid Pots Feature

### Overview
The pre-made pots feature allows Admin/Manager users to create a catalog of finished orchid pot compositions that customers can browse and purchase directly, without customization.

### Business Use Cases
1. **Quick Purchase**: Customers who want immediate solutions
2. **Gift Giving**: Ready-made elegant gift options
3. **Seasonal Collections**: Holiday-themed arrangements
4. **Bestseller Showcase**: Popular combinations
5. **Inventory Clearance**: Move excess stock

**Route**: `/premade-pots`
**Access**: Admin, Manager roles only
